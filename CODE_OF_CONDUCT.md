# Code of conduct

Folio is meant to be a language anyone can pick up, and its project is meant to be a place anyone can help. So
in issues, pull requests, discussions and anywhere else Folio's work is done:

- Be kind and patient, especially with people who are new to programming or to Folio. Questions are welcome.
- Talk about the code and the ideas, never the person.
- Assume good intent, and say clearly and politely when something isn't right.
- No harassment, insults, or unwelcome attention, and nothing that demeans anyone for who they are.

Folio follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
and its full text applies here.

## Reporting

If someone's behaviour worries you, tell the maintainer privately through a
[private report](https://github.com/samyyy2423/folio/security/advisories/new). That form is meant for security
problems, but only the maintainer sees it, so it works for this too. Start its title with "Conduct". Reports
are kept confidential, and the maintainer will act as the Contributor Covenant's enforcement guidelines describe.
