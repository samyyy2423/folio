# Installation

Moth is one program, with nothing else to install.

- **Windows:** download `moth-windows.exe` from [the latest release](https://github.com/samyyy2423/moth/releases/latest),
  save it as `moth.exe` in a folder on your `PATH`.
- **Linux:** download `moth-linux`, save it as `moth` in a folder on your `PATH`, and run `chmod +x moth`.

Check it works:

```text
moth
```

starts the Moth shell, where you can type Moth a line at a time; `quit` leaves it. Without installing anything,
the [playground](https://samyyy2423.github.io/moth/) runs Moth in your browser.

Editors: VS Code has the Moth extension, and Neovim, Helix and Zed are set up as
[editors/README.md](https://github.com/samyyy2423/moth/blob/main/editors/README.md) says, all through `moth lsp`.
