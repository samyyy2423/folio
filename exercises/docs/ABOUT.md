# About

Moth is a programming language that reads like plain English. A program says what it does:

```text
set fruits to list of "apple", "pear"
for each fruit in fruits
    say "I like " fruit
end
```

It's small enough to learn in an afternoon, and built like a real language underneath: a compiler written in
Moth that makes Windows and Linux programs as fast as C, three engines in the browser that agree with it on
every result, a debugger that runs backwards, and a standard library from web servers and databases to
pictures and encryption. Its mistakes are written to be read by a person: what went wrong, where, and often
what was meant.

Moth is open source, under the Apache License 2.0.
