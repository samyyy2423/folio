# Learning

- [Learn Moth in an afternoon](https://samyyy2423.github.io/moth/learn.html): eleven short lessons, each with a
  program to run and change in your browser.
- [The language](https://github.com/samyyy2423/moth#the-language): all of Moth on one page.
- [The cookbook](https://github.com/samyyy2423/moth/blob/main/docs/cookbook/README.md): tested recipes for real
  work, from CSV and JSON to web servers and games.
- [Examples](https://samyyy2423.github.io/moth/docs/examples.html): small whole programs, each one click from
  running.
