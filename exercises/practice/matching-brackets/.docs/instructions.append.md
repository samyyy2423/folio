## In Moth

`is_paired(value)` gives yes if every `[`, `{` and `(` in the text is closed by its own `]`, `}` or `)`, in order. Other characters don't matter. In Moth's text, a `{` right before a letter starts a value, so write `\{` for the brace.

Write it in `matching_brackets.moth`, and run the tests with `moth test matching_brackets.test.moth`.
