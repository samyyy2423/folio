# Help

- **The language** is on one page: [Moth's README](https://github.com/samyyy2423/moth#the-language), and
  [SPEC.md](https://github.com/samyyy2423/moth/blob/main/SPEC.md) has every rule.
- **Try a line** in the [playground](https://samyyy2423.github.io/moth/), in your browser, or in the Moth
  shell: run `moth` with nothing after it.
- **The standard library** has a reference with an example for every function:
  [samyyy2423.github.io/moth/docs/](https://samyyy2423.github.io/moth/docs/).
- **Mistakes say where and why.** Read the whole message: it names the line, the column, and what was there.
  `moth check` finds many without running anything.
- **Ask** in the [Moth repository's issues](https://github.com/samyyy2423/moth/issues), with the code, what it
  said, and what you expected.
