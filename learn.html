    Where next

    That's the heart of Moth. When you're ready for more:

    • The playground has examples to open and change: games, drawings, a neural network that reads your handwriting.
    • The language has all of Moth on one page.
    • The standard library has every function Moth carries, from JSON to web servers, each with an example.
    • The examples are small, whole programs to open in the playground: the Game of Life, a clock, the Mandelbrot set, a Caesar cipher and more.
    • The cookbook has recipes for real work: CSV and JSON, web APIs, a server with a database, command-line tools, charts, games and tests.
    • Download Moth for Windows or Linux, and moth build turns your program into one of its own, as fast as C.
    • Build a web app: a guestbook with a database, in Moth, from start to finish.
