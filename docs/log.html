What it's for

Logging, as Python's logging module does it: a line for each thing that happened, with the time, how much it matters, and what it was, for those that matter at least as much as the level set, to the error output or added to the end of a file.

use "log.moth" as log
log's info("started")                  # 2026-11-04 10:15:00 INFO started, on the error output
log's warning("the disk is almost full")
log's debug("cache hit")                # written only at the debug level
log's error("can't reach the database") # and critical, the most
log's set_level("debug")               # debug, info (the first level), warning, error or critical
log's to_file("app.log")               # each line added to the end of app.log (built with --allow-libraries)
log's to_error_output()                # back to the error output
log's set_name("db")                   # 2026-11-04 10:15:00 INFO db: connected
log's set_format("%level%: %message%") # %time%, %level%, %name% and %message%, as you want them
say log's lines()                      # the lines it's written since the program started

Writing to a file goes through system.moth, so a program that logs to one is built with --allow-libraries.
