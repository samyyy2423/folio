The cookbook

Recipes for real work.

Short recipes for what people make: data from files and the web, servers with databases, tools for the command line, charts, games, work on every core, and tests. Each starts from a task, gives the whole program, and shows what it says.

8 recipes

Every one is run as it's written, by Moth's tests, on every push: what you read is what the code does today.

Read and write CSV and JSONYou have a spreadsheet's worth of sales as CSV, and want totals by region, written out as JSON for another program, and as CSV again for the spreadsheet. Call a web APIYou want to ask a web service for data, as JSON, and send it some: here, GitHub's REST API, for a repository's stars and its open issues, and to open a new issue. A web API with a databaseYou want a small service of your own: a to-do list other programs can read and change over HTTP, as JSON, kept in a database so it's there after a restart. A command-line tool with optionsYou want a program people run from a terminal, with options in the usual form (--top 3, -t 3, --top=3, a flag like -k), names after them, and a… A data script: statistics and a chartYou have a year of figures, and want the numbers that sum them up, how two of them go together, and a chart to show someone. A gameYou want a game: a window drawn again about 60 times a second, keys that move something, things that move by themselves, and a score. Work on every coreYou have work that takes a while and splits into parts that don't need each other: here, counting the primes up to four million, in eight ranges. TestingYou want to know your code does what you meant, now and after every change.
