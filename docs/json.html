What it's for

Reads JSON, the format most of the web speaks, into Moth's own values: an object becomes a dictionary, an array a list, true and false yes and no, and null nothing.

use "json.moth" as json
set data to json's parse(read "data.json")
say item "name" of data

A mistake in the JSON is a fail with, which says where: catch it with try.
