What it's for

Web pages, made in Moth: headings, text, links, pictures, lists, tables, text boxes, buttons and the rest, styled with CSS of the page's own or Moth's, shown where the program runs on the web (the playground, or a page moth build --web made, as the whole window). What's clicked, typed or chosen on it comes back to the program: when the page is used with what, what a dictionary of its "type" ("click", "enter" for Enter in a text box, or "change"), the "name" of what was used, its "value", and "values": every text box's, checkbox's and dropdown's value on the page, by its name. Show the page again to change it.

use "page.moth" as page
set todos to list of "Feed the cat"
to view
    set p to page's new("To do")
    page's heading(p, "To do")
    page's text_box(p, "new", "What needs doing?")
    page's button(p, "add", "Add")
    page's start_list(p)
    for each t in todos
        page's list_item(p, t)
    end
    page's end_list(p)
    page's show(p)
end
when the page is used with what
    if item "name" of what is "add"
        add item "new" of item "values" of what to todos
        view()
    end
end
view()

Every text is shown as it is, never read as HTML; html() puts HTML in as it's written, and anything in it with a data-moth="name" is used as a button is. A page is shown by writing it to the file "<page>", which the web shows instead of keeping. Elsewhere, html_of() is the page's HTML, to write to a file of its own or for server.moth to send; a site's pages have menu(), list_link() and forms, start_form() to end_form(), whose fields the browser sends to the server, as a page shown in the playground has no server to send to.
