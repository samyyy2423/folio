Every library · The source

What it's for

Windows' own windows, buttons, text boxes, lists, menus and file boxes, as a program folio build makes can use them: real ones, through user32.dll and the rest, which look and behave as every other program's.

use "windows.folio" as ui
to say_hello
    ui's message(w, "Hello, " + ui's text_of(name))
end
set w to ui's window("Hello", 360, 140)
set name to ui's text_box(w, 20, 20, 200, 26)
ui's button(w, "Greet", 230, 20, 100, 28, say_hello)
ui's run()

Places and sizes are in pixels as at 100% on the screen, made bigger for a screen set larger. What happens calls the function given for it, a function of the program's: a button's with nothing, a checkbox's with whether it's ticked, a list's or a dropdown's with the item chosen, a text box's with its text, a timer's with nothing, and a window's resizing with its new width and height. A program that uses it is built with --allow-libraries.
