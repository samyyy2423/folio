What it's for

Encryption, as Python's cryptography has it with AESGCM: AES with a 128, 192 or 256-bit key, in GCM, which hides a message and proves it wasn't changed. In Moth alone, so it works everywhere.

use "crypto.moth" as crypto
set key to crypto's new_key()                          # 32 random bytes: keep them secret
set sealed to crypto's encrypt(key, "meet at noon")    # a fresh nonce, the message hidden, and its tag
say crypto's decrypt(key, sealed) as text              # a mistake if the key is wrong or a byte changed
set salt to crypto's new_salt()                        # 16 random bytes, kept with what the key locks
set key to crypto's key_from_password("correct horse", salt, 200000)   # PBKDF2 with SHA-256

aes_gcm_encrypt(key, nonce, message, extra) and aes_gcm_decrypt(key, nonce, sealed, extra) are GCM itself, as NIST SP 800-38D has it: a 12-byte nonce, never used twice with one key, and extra, text or bytes that are checked but not hidden (or nothing). A message and a key are text or bytes; what comes back is bytes. new_key, new_salt and encrypt take the system's own randomness, so they work in a program moth build makes.
