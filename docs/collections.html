What it's for

Collections, as Python's collections, heapq and bisect have them: counting things, a queue both ends of which are quick, a heap that gives the smallest first, and a sorted list kept sorted. In Folio alone, so it works everywhere.

use "collections.folio" as c
set counts to c's counted(split "a b a c a b" by " ")    # (dictionary where "a" is 3, "b" is 2, "c" is 1)
say c's most_common(counts, 2)                           # [(record with value "a", count 3, ...), ...]

set q to c's queue()                     # a deque
c's push(q, 1)                           # at the back; push_front at the front
say c's pop_front(q)                     # 1; pop at the back; size(q), peek_front(q), peek(q), items_of(q)

set h to c's heap()                      # the smallest first: numbers, or text
c's heap_push(h, 5)
say c's heap_pop(h)                      # heap_peek(h), heap_size(h)

set xs to list of 1, 3, 5
say c's where_sorted(xs, 4)              # 3: where 4 goes, after anything equal (bisect)
c's insert_sorted(xs, 4)                 # [1, 3, 4, 5]

set by_first to c's grouped(split "apple avocado banana" by " ", first_letter)   # a dictionary of lists

heap_push and the rest take a record heap() made, and push and the rest one queue() made.
