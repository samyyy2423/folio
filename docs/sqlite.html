What it's for

A database in a file, through SQLite itself: the library that comes with Windows (winsqlite3.dll) and with most Linux systems (libsqlite3.so.0). Each row a query gives is a dictionary of its columns.

use "sqlite.moth" as sqlite
set people to sqlite's open("people.db")
sqlite's run(people, "create table if not exists people (name text, age integer)")
sqlite's run_with(people, "insert into people values (?, ?)", list of "Sam", 20)
for each row in sqlite's query(people, "select name, age from people")
    say item "name" of row + " is " + item "age" of row
end
sqlite's close(people)

A program that uses it is built with --allow-libraries. A mistake SQLite finds is a fail with, which says what SQLite said: catch it with try.
