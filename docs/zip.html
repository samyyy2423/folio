What it's for

Squeezes bytes smaller and back, as gzip and .zip files do, in Folio alone: DEFLATE (RFC 1951), gzip (RFC 1952) and zip archives. Each takes text or bytes and gives bytes.

use "zip.folio" as zip
write zip's gzip(read "notes.txt") to "notes.txt.gz"
say zip's gunzip(read bytes "notes.txt.gz") as text
write zip's zipped(list of "a.txt", "b.txt", list of "one", "two") to "both.zip"
set files to zip's unzipped(read bytes "both.zip")       # a dictionary: each file's name, its bytes
say item "a.txt" of files as text

A file that isn't one of these, or that's damaged, is a fail with that says why: catch it with try.
