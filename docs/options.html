What it's for

A program's command line read, as Python's argparse reads it: options with values, flags, and the names in order after them, with a --help made from what each is for. In Moth alone, so it works everywhere.

use "options.moth" as options
set p to options's parser("greet", "Says hello to someone.")
options's option(p, "name", "n", "who to greet", "World")   # --name Sam, -n Sam or --name=Sam; World if not
options's option(p, "times", "t", "how many times", 1)      # a default that's a number makes it a number
options's flag(p, "loud", "l", "shout it")                  # --loud or -l: yes; no if it isn't there
options's positional(p, "file", "the file to greet from")   # needed, in order
options's rest(p, "more", "other files")                    # the rest, as a list, which can be empty
set given to options's parse(p, arguments)                  # a dictionary: name, times, loud, file, more
say item "name" of given

--help or -h says how to use it, and stops the program. A mistake on the command line (an option it doesn't know, one with no value, a name missing, one too many) says how to use it and why on the error output, and stops the program with 2, as argparse does. parse_or_fail is parse with a fail with instead, which try can catch: its why is the usage, then a line that says what's wrong; and given a --help, it gives the dictionary with "help" set to yes. help_text(p) is what --help says. A short name can be "", for none.
