What it's for

ONNX models, run by ONNX Runtime through its C API: a model trained in PyTorch or anything else that saves ONNX, given arrays (arrays.moth) and giving arrays back. ONNX Runtime comes with Windows 11 (System32\onnxruntime.dll); elsewhere, put onnxruntime.dll (or Linux's libonnxruntime.so) from its release page, github.com/microsoft/onnxruntime/releases, beside the program.

use "onnx.moth" as onnx
use "arrays.moth" as arrays
set model to onnx's load("model.onnx")
say onnx's inputs(model)            # each a record: name, type ("float", "double" or "int64") and shape,
                                    # -1 for an axis of any length
set x to arrays's array(list of (list of 1, 2, 3))
set answers to onnx's run(model, dictionary where "X" is x)   # each output by its name, an array
say item "Y" of answers
onnx's close(model)

A program that uses it is built with --allow-libraries. Inputs are converted to the type the model takes: floats, doubles, or whole numbers of 64 bits. ONNX Runtime's mistakes are a fail with that says what it said.
