What it's for

ONNX models, run by ONNX Runtime through its C API: a model trained in PyTorch or anything else that saves ONNX, given arrays (arrays.folio) and giving arrays back. ONNX Runtime comes with Windows 11 (System32\onnxruntime.dll); elsewhere, put onnxruntime.dll (or Linux's libonnxruntime.so) from its release page, github.com/microsoft/onnxruntime/releases, beside the program.

use "onnx.folio" as onnx
use "arrays.folio" as arrays
set model to onnx's load("model.onnx")
say onnx's inputs(model)            # each a record: name, type ("float", "double" or "int64") and shape,
                                    # -1 for an axis of any length
set x to arrays's array(list of (list of 1, 2, 3))
set answers to onnx's run(model, dictionary where "X" is x)   # each output by its name, an array
say item "Y" of answers
onnx's close(model)

# a session with settings: how many threads a run uses, how much the graph is optimized ("none", "basic",
# "extended" or "all", the default), and any of ONNX Runtime's session settings by name
set model to onnx's load_with("model.onnx", dictionary where "threads" is 4, "session.disable_quant_qdq" is "1")

A program that uses it is built with --allow-libraries. Inputs are converted to the type the model takes: floats, doubles, or whole numbers of 64 bits. ONNX Runtime's mistakes are a fail with that says what it said.

An output can stay where ONNX Runtime made it, unread, and go back into the model as an input as it is, as a language model's cache of keys and values does from one token to the next:

set got to onnx's run_keeping(model, inputs, list of "present")   # "present" kept, the rest arrays
set present to item "present" of got                              # an ONNX value: onnx's shape_of(present)
onnx's run(model, dictionary where "past" is present, "x" is x)   # given back, not copied
say onnx's numbers_from(present, 1, 10)                           # 10 of its numbers, the rest unread
say onnx's array_of(present)                                      # all of them, as an array
onnx's release(present)                                           # its memory given back

A kept value holds ONNX Runtime's memory until it's released.

onnx's load_with(path, settings)

A model from a file, its session made with these settings, a dictionary: - "threads": how many of the processor's threads a run uses (0, the default, is ONNX Runtime's choice); - "optimization": how much the graph is optimized when it's loaded, "none", "basic", "extended" or "all"; - any of ONNX Runtime's session settings, by its name (onnxruntime_session_options_config_keys.h), as text:

Inputs

  • path
  • settings

Written to load_with with path, settings, at onnx.folio line 189

Example

"session.disable_quant_qdq" is "1" lets weights stored as 8-bit whole numbers be made floats once, when the
model is loaded, instead of on every run, which is faster on the processor and takes more memory.
