What it's for

Text: patterns to find, check and replace (regular expressions), numbers written with so many decimals or with commas, text padded to a width, and CSV, read and written. In Moth alone, so it works everywhere.

use "text.moth" as text
say text's matches("^[a-z]+@[a-z]+\\.com$", "sam@moth.com")     # yes
set found to text's find("(\\d+)-(\\d+)", "pages 12-40")
say text of found " " item 2 of groups of found                  # 12-40 40
say text's replace_all("\\s+", "a   lot  of space", " ")          # a lot of space
say text's number_text(3.14159, 2) " " text's grouped(1234567.5)  # 3.14 1,234,567.5
say text's csv_rows("name,age\nSam,20\n\"Lee, Ana\",31")          # [["name", "age"], ...]

A pattern has: letters and digits for themselves; . any character but a new line; [abc], [a-z], [^0-9] a character of a set or not; \d a digit, \w a letter, digit or _, \s a space, tab or new line (\D, \W and \S none of those); \b where a word starts or ends; ^ and $ the start and the end; ( ) a group, which is kept, (?: ) one that isn't; | either side; * any number, + one or more, ? one or none, {2}, {2,} and {2,5} so many, each taking as many as it can, or as few with a ? after it. \ before any other character is that character. (?i) at the very start makes it not mind capitals. In Moth's own text, a \ is written \\.

A match is a record: its text, at (where it starts, from 1), size (how many characters), and groups (each group's text, or nothing for a group that took no part).
