The towers of Hanoi

Moves a stack of discs from one peg to another, one disc at a time, never a bigger disc on a smaller one. A function that calls itself does the whole puzzle in a few lines: move all but the bottom disc out of the way, move the bottom one, then move the rest back on top of it.

Run it in the playground · The source

# The towers of Hanoi
# Moves a stack of discs from one peg to another, one disc at a time, never a bigger disc on a smaller one. A
# function that calls itself does the whole puzzle in a few lines: move all but the bottom disc out of the way,
# move the bottom one, then move the rest back on top of it.

set moves to 0

to hanoi with discs, from_peg, to_peg, spare_peg, show
    if discs is 0
        return
    end
    hanoi(discs - 1, from_peg, spare_peg, to_peg, show)
    add 1 to moves
    if show
        say "move disc " + discs + " from " + from_peg + " to " + to_peg
    end
    hanoi(discs - 1, spare_peg, to_peg, from_peg, show)
end

hanoi(3, "A", "C", "B", yes)
say moves + " moves for 3 discs"

for each discs in list of 5, 10, 15
    set moves to 0
    hanoi(discs, "A", "C", "B", no)
    say moves + " moves for " + discs + " discs"
end

The game of life

Conway's cellular automaton: on a grid, a live cell with two or three live neighbours lives on, and a dead cell with exactly three comes alive. A glider, five cells that walk across the grid, shown for four generations.

Run it in the playground · The source

# The game of life
# Conway's cellular automaton: on a grid, a live cell with two or three live neighbours lives on, and a dead
# cell with exactly three comes alive. A glider, five cells that walk across the grid, shown for four
# generations.

set size to 8
set alive to empty dictionary

to key_of with row, column
    return row + "," + column
end

to is_alive with row, column
    return key_of(row, column) is in alive
end

to neighbours with row, column
    set count to 0
    for each dr in list of -1, 0, 1
        for each dc in list of -1, 0, 1
            if not (dr is 0 and dc is 0) and is_alive(row + dr, column + dc)
                add 1 to count
            end
        end
    end
    return count
end

to show_grid with generation
    say "generation " + generation
    for each row from 1 to size
        set line to ""
        for each column from 1 to size
            if is_alive(row, column)
                set line to line + "#"
            else
                set line to line + "."
            end
        end
        say line
    end
end

for each cell in list of (list of 1, 2), (list of 2, 3), (list of 3, 1), (list of 3, 2), (list of 3, 3)
    set item key_of(item 1 of cell, item 2 of cell) of alive to yes
end

for each generation from 1 to 4
    show_grid(generation)
    set next to empty dictionary
    for each row from 1 to size
        for each column from 1 to size
            set n to neighbours(row, column)
            if n is 3 or (n is 2 and is_alive(row, column))
                set item key_of(row, column) of next to yes
            end
        end
    end
    set alive to next
end

The words a text uses most

Counts every word in a paragraph with a dictionary, leaves out the little ones, and puts the rest in order by how often each comes up: what a search engine's first step looks like.

Run it in the playground · The source

# The words a text uses most
# Counts every word in a paragraph with a dictionary, leaves out the little ones, and puts the rest in order
# by how often each comes up: what a search engine's first step looks like.

set paragraph to "The folio flew to the lamp, and the lamp burned bright. The night was long, and the folio "
set paragraph to paragraph + "was patient; it waited by the lamp until the night was over and the light was gone."

to letters_of with word
    set kept to ""
    for each c in split word by ""
        if not (c is in list of ",", ".", ";")
            set kept to kept + c
        end
    end
    return kept
end

set little to list of "the", "and", "to", "a", "it", "by", "was", "of"
set counts to empty dictionary
for each word in split (lowercase of paragraph) by " "
    set word to letters_of(word)
    if word is not "" and not (word is in little)
        if word is in counts
            set item word of counts to item word of counts + 1
        else
            set item word of counts to 1
        end
    end
end

set ranked to empty list
for each word in keys of counts
    add (record with word word, times item word of counts) to ranked
end
set ranked to ranked in order by times
for each k from 1 to 5
    set r to item (length of ranked - k + 1) of ranked
    say word of r + ": " + times of r
end

A bank account

A kind is a sort of record with functions of its own. An account keeps its balance and a history, refuses to go below nothing, and says what it is with shown, which say uses.

Run it in the playground · The source

# A bank account
# A kind is a sort of record with functions of its own. An account keeps its balance and a history, refuses to
# go below nothing, and says what it is with `shown`, which `say` uses.

kind account with owner, balance or 0
    to deposit with self, amount
        if amount is at most 0
            fail with "a deposit has to be more than nothing, not " + amount
        end
        set self's balance to self's balance + amount
    end
    to withdraw with self, amount
        if amount is greater than self's balance
            fail with self's owner + " has only " + self's balance + ", not " + amount
        end
        set self's balance to self's balance - amount
    end
    to shown with self
        return self's owner + "'s account: " + self's balance
    end
end

set ada to account("Ada")
ada's deposit(120.50)
ada's withdraw(20.25)
say ada

try
    ada's withdraw(500)
if it fails with why
    say "refused: " + why
end

set bank to list of ada, account("Lee", 40), account("Sam", 310)
set total to 0
for each a in bank
    set total to total + balance of a
end
say "the bank holds " + total

Secret messages

Julius Caesar's cipher moves each letter a few places along the alphabet. Moving it back reads the message, and trying all 25 shifts breaks it: the one with the most common English letters in it wins.

Run it in the playground · The source

# Secret messages
# Julius Caesar's cipher moves each letter a few places along the alphabet. Moving it back reads the message,
# and trying all 25 shifts breaks it: the one with the most common English letters in it wins.

set alphabet to "abcdefghijklmnopqrstuvwxyz"

to shifted with message, by
    set made to ""
    for each c in split message by ""
        set at to position of (lowercase of c) in alphabet
        if at is 0
            set made to made + c
        else
            set moved to item (remainder of (at - 1 + by) divided by 26 + 1) of alphabet
            if c is not lowercase of c
                set moved to uppercase of moved
            end
            set made to made + moved
        end
    end
    return made
end

to score_of with message
    set score to 0
    for each c in split (lowercase of message) by ""
        if c is in list of "e", "t", "a", "o", "i", "n", "s", "h", "r"
            add 1 to score
        end
    end
    return score
end

set secret to shifted("Meet me by the old lamp at nine.", 7)
say "sent: " + secret
say "read: " + shifted(secret, -7)

set best to 0
for each by from 1 to 25
    if score_of(shifted(secret, -by)) is greater than score_of(shifted(secret, -best))
        set best to by
    end
end
say "broken: the shift was " + best + ", and it says " + shifted(secret, -best)

Roman numerals

Writes whole numbers the way Rome did and reads them back, with a pair of lists that walk down from the biggest value; then checks every number from 1 to 3,999 comes back as itself.

Run it in the playground · The source

# Roman numerals
# Writes whole numbers the way Rome did and reads them back, with a pair of lists that walk down from the
# biggest value; then checks every number from 1 to 3,999 comes back as itself.

set values to list of 1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1
set numerals to list of "M", "CM", "D", "CD", "C", "XC", "L", "XL", "X", "IX", "V", "IV", "I"

to roman with n
    set made to ""
    for each k from 1 to length of values
        repeat while n is at least item k of values
            set made to made + item k of numerals
            set n to n - item k of values
        end
    end
    return made
end

# whether the numeral is in the written number, starting at `at`
to starts_at with written, at, numeral
    set last to at + length of numeral - 1
    if last is greater than length of written
        return no
    end
    return items at to last of written is numeral
end

to number_from with written
    set total to 0
    set at to 1
    for each k from 1 to length of values
        set numeral to item k of numerals
        repeat while starts_at(written, at, numeral)
            set total to total + item k of values
            set at to at + length of numeral
        end
    end
    return total
end

for each year in list of 1066, 1492, 1969, 2026
    say year + " is " + roman(year)
end
say "MMXXVI is " + number_from("MMXXVI")

set wrong to 0
for each n from 1 to 3999
    if number_from(roman(n)) is not n
        add 1 to wrong
    end
end
say "checked 1 to 3999: " + wrong + " wrong"

The Mandelbrot set, in text

For each point of the plane, a number that starts at 0 is squared and the point added, over and over; the points where it never runs away are the set. Each character is a point, darker the longer it held out.

Run it in the playground · The source

# The Mandelbrot set, in text
# For each point of the plane, a number that starts at 0 is squared and the point added, over and over; the
# points where it never runs away are the set. Each character is a point, darker the longer it held out.

set shades to " .:-=+*#%@"
for each row from 0 to 20
    set line to ""
    set y to row / 10 - 1
    for each column from 0 to 60
        set x to column / 24 - 2
        set zx to 0
        set zy to 0
        set steps to 0
        repeat while steps is less than 30 and zx * zx + zy * zy is at most 4
            set next_x to zx * zx - zy * zy + x
            set zy to 2 * zx * zy + y
            set zx to next_x
            add 1 to steps
        end
        set line to line + item (((steps * 9 / 30) rounded down) + 1) of shades
    end
    say line
end

A snowflake, drawn

Koch's snowflake: each side of a triangle becomes four sides a third as long, with a point in the middle, and so on, as deep as asked. The turtle starts in the middle, facing up, and draws wherever it moves.

Run it in the playground · The source

# A snowflake, drawn
# Koch's snowflake: each side of a triangle becomes four sides a third as long, with a point in the middle, and
# so on, as deep as asked. The turtle starts in the middle, facing up, and draws wherever it moves.

to side with long, depth
    if depth is 0
        move forward long
        return
    end
    side(long / 3, depth - 1)
    turn left 60
    side(long / 3, depth - 1)
    turn right 120
    side(long / 3, depth - 1)
    turn left 60
    side(long / 3, depth - 1)
end

pen up
move back 90
turn left 90
move forward 160
turn right 120
pen down
pen color "skyblue"
pen width 2
for each k from 1 to 3
    side(320, 4)
    turn right 120
end
say "a snowflake of " + 3 * 4 * 4 * 4 * 4 + " sides"
