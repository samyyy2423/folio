What it's for

TOML (v1.0), the settings files Python's tomllib reads (pyproject.toml, Cargo.toml and many more): read into dictionaries and lists, and written back. In Moth alone, so it works everywhere.

use "toml.moth" as toml
set settings to toml's read_toml(read "settings.toml")
say item "name" of item "package" of settings
write toml's toml_of(settings) to "settings.toml"

Tables are dictionaries; arrays are lists; strings, numbers, true and false are text, numbers, yes and no; dates and times stay text, as written ("1979-05-27T07:32:00Z"). A file that isn't TOML is a fail with that says which line, and why: catch it with try.

toml's read_toml(words)

the settings TOML text holds, as a dictionary: tables as dictionaries, arrays as lists, and dates and times as text; a mistake is a fail with that says which line

Example

use "toml.moth" as toml
set d to toml's read_toml("a = \"tab\\there \\u00e9 \\U0001F600\"\nb = 'C:\\path\\x'\nc = 0xff\nd = 0o17\ne = 0b101\nf = 1_000\ng = -3.5\nh = 5e3\ni = 1.5E-2\nj = true\nk = false\nl = 1979-05-27T07:32:00Z\nm = 07:32:00\nn = [1, [2, 3], \"x\",]\no = { x = 1, y.z = 2 }\n")
say d
(dictionary where "a" is "tab\there é 😀", "b" is "C:\\path\\x", "c" is 255, "d" is 15, "e" is 5, "f" is 1000, "g" is -3.5, "h" is 5000, "i" is 0.015, "j" is yes, "k" is no, "l" is "1979-05-27T07:32:00Z", "m" is "07:32:00", "n" is [1, [2, 3], "x"], "o" is (dictionary where "x" is 1, "y" is (dictionary where "z" is 2)))
