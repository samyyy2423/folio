What it's for

Talking to large language models: Anthropic's Messages API, and any API that speaks OpenAI's (OpenAI's own, and local servers such as Ollama, LM Studio and vLLM). Messages and a system prompt, answers streamed as they're written, tools the model can use, answers in JSON of a shape you give, embeddings, and a small search of vectors by cosine similarity, on arrays.folio.

use "ai.folio" as ai
set claude to ai's anthropic("claude-opus-5-5")     # its key from ANTHROPIC_API_KEY
say ai's answer(claude, "Name three moths.")
set reply to ai's chat(claude, (list of (record with role "user", content "Hi")), dictionary where "system" is "Be brief.")
say reply's text " " reply's stop_reason " " reply's usage's output_tokens
to shown_as_written with piece
    say piece                                       # each piece of the answer as it comes
end
ai's stream(claude, "Write a haiku.", shown_as_written)
set weather to ai's tool("get_weather", "The weather in a city", dictionary where "type" is "object",
    "properties" is (dictionary where "city" is dictionary where "type" is "string"), function with input gives "sunny")
say ai's chat_with_tools(claude, "Is it sunny in Paris?", list of weather)'s text
say ai's answer_json(claude, "A folio's name and wingspan in mm", dictionary where "type" is "object",
    "properties" is (dictionary where "name" is (dictionary where "type" is "string"), "wingspan" is
    (dictionary where "type" is "number")))
set local to ai's openai_compatible("http://localhost:11434/v1", "nomic-embed-text")   # Ollama, no key
set vectors to ai's embed(local, list of "folios fly at night", "bees fly by day")   # an array, a row each

openai(model) is OpenAI's own. Keys come only from the environment: ANTHROPIC_API_KEY for anthropic(), and OPENAI_API_KEY for openai(), and for openai_compatible(base_url, model, yes), a server that wants a key; they're never kept in a value or shown. Options, a dictionary: system, max_tokens, effort (Anthropic's output_config.effort), temperature (OpenAI's), and for a client base_url. A reply is a record: text, stop_reason, tool_calls (each a record of id, name and input), usage (input_tokens and output_tokens), and message, the model's turn to add to a conversation. On Claude Fable 5.1, Opus 5.5, Opus 5 and Sonnet 5.5, a request the model declines is run again on another model (Anthropic's server-side fallbacks); "fallbacks" is no in a client's options to turn that off. A program that uses it is built with --allow-libraries and --allow-net. The API's mistakes are a fail with that says what it said.

Inputs

  • model optional: "claude-opus-5-5" if it's left out

the k vectors most like the query (a vector, or an array of one row, as embed gives for one text), by cosine similarity, most alike first: each a record of key and score

Inputs

  • index
  • query
  • k optional: 5 if it's left out

Written to search with index, query, k or 5, at ai.folio line 878

Example
