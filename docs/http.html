What it's for

Asking web servers, as Python's urllib.request (and the requests package) do: any method, headers of one's own, bodies of text, bytes or JSON, redirects followed, and answers sent in chunks or squeezed with gzip, over HTTP and HTTPS, on sockets.folio. A program folio build makes can use it, built with --allow-libraries.

use "http.folio" as http
set r to http's get("https://example.com/")
say status of r                      # 200; reason of r is "OK"
say item "content-type" of headers of r   # each header's name in small letters
say text of r                        # what it sent, as text; body of r is its bytes; url of r where it ended
set r to http's request("PUT", "https://example.com/api/1", record with name "Sam",
    dictionary where "authorization" is "Bearer xyz")   # a record, list or dictionary goes as JSON
set r to http's post("https://example.com/form", http's form_of(dictionary where "q" is "folio"))
http's check(r)                      # a mistake if the server said no (400 and up)
say http's get_json("https://example.com/data.json")   # what its JSON says
set r to http's put("https://example.com/api/1", record with name "Sam")   # and patch the same way
set r to http's delete("https://example.com/api/1")
set r to http's head("https://example.com/big.zip")      # the headers alone
say http's encoded("a b&c") " " http's decoded("a%20b%26c")   # a%20b%26c a b&c
http's wait_at_most(5000)                # 5 seconds for an answer
http's trust("company-ca.pem")           # a company's own certificates too

head, get, post, put, patch and delete are request with that method. A request fails only when it can't be made or answered: an answer of 404 or 500 is a response like any other. Redirects (301, 302, 303, 307, 308) are followed, up to 10, as browsers do: after a 303, or a 301 or 302 to a POST, as a GET with no body; Authorization isn't sent on to another host. wait_at_most(ms) is how long an answer may take (30000); trust(file) trusts a PEM file's certificates besides the system's. HTTPS uses OpenSSL as sockets.folio does.
