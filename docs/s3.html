What it's for

Amazon S3 and the stores that speak its language (MinIO, Cloudflare R2, Backblaze B2, Ceph and more), as Python's boto3 has them: objects put, got, listed and deleted, buckets made and removed, and presigned URLs that let anyone with one get (or put) an object for a while, each request signed with AWS Signature Version 4, over http.folio. A program folio build makes can use it, built with --allow-libraries.

use "s3.folio" as s3
set store to s3's client("https://s3.eu-west-1.amazonaws.com", "eu-west-1", access_key, secret_key)
set store to s3's client("http://localhost:9000", "us-east-1", "minioadmin", "minioadmin")   # MinIO
set store to s3's from_environment()     # AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_REGION, ...
s3's put_object(store, "photos", "2026/cat.png", read bytes "cat.png", "image/png")
set data to s3's get_object(store, "photos", "2026/cat.png")       # bytes
for each found in s3's list_objects(store, "photos", "2026/")       # every one, page after page
    say key of found " " size of found " " modified of found
end
say s3's head_object(store, "photos", "2026/cat.png")   # its size, type, etag and modified; nothing if none
s3's delete_object(store, "photos", "2026/cat.png")
say s3's presigned_url(store, "GET", "photos", "2026/cat.png", 3600)   # good for an hour
s3's create_bucket(store, "photos")       # and delete_bucket; list_buckets says each one's name

A client is a record: endpoint, region, access_key, secret_key, token (a session's, from temporary credentials, or nothing), path_style (buckets in the path, as MinIO and most stores want, yes; or in the host's name, as AWS wants, no: client() picks by the endpoint) and sign_payload (yes: each body's SHA-256 is signed; no sends UNSIGNED-PAYLOAD, which is quicker for big objects over HTTPS). A store that says no is a fail with with its code and message, as "S3 said NoSuchKey (404): The specified key does not exist.". sign() is Signature Version 4 itself, for any AWS service's requests.

s3's sign(store, method, path, query, headers, payload_hash, stamp)

A request signed: its method, path (as it's sent, already encoded), query (a dictionary, not encoded), headers (a dictionary, host among them, and x-amz-date), the hex SHA-256 of its body (or "UNSIGNED-PAYLOAD") and the time as "20130524T000000Z". A record: canonical_request, string_to_sign, signature and authorization (the Authorization header's value).

Inputs

  • store

  • path

  • headers

  • stamp
