What it's for

Fractions, exact, as Python's fractions has them: kept as text, "3/4", "-1/2", or "2" for a whole one, always in lowest terms with the sign on top, so say shows one and is compares two. Each function takes such text, a whole number of any size, or a decimal written out ("0.75" is 3/4, and a number counts as it's shown, so 0.1 is 1/10), and gives text back. In Moth alone, on big.moth.

use "fractions.moth" as f
say f's plus("1/3", "1/6")            # 1/2
say f's times("2/3", 9)               # 6
say f's divided(1, 3)                 # 1/3
say f's fraction(6, -8)               # -3/4
say f's as_decimal("1/3", 5)          # 0.33333: to 5 places, a half away from 0
say f's compare("1/3", 0.33)          # 1: -1, 0 or 1, as with big.moth
say f's top_of("3/4") " " f's bottom_of("3/4")   # 3 4

minus, power (to a whole number, below 0 too), negated, absolute, rounded_down, rounded_up and rounded (a half away from 0) are here too.
