What it's for

Sets, as Python's set has them: each thing once, found at once however many there are, with unions, intersections and differences. A set holds numbers and text, as a dictionary's keys can be, keeps them in the order they were put in, and say shows one as {1, 2, 3}. In Moth alone, so it works everywhere.

use "sets.moth" as sets
set seen to sets's set_of(list of 1, 2, 2, 3)
sets's put(seen, 4)
say seen                                   # {1, 2, 3, 4}
say sets's has(seen, 2)                    # yes
say sets's both(seen, sets's set_of(list of 2, 9))    # {2}: in both (intersection)
say sets's union(seen, sets's set_of(list of 9))       # {1, 2, 3, 4, 9}
say sets's only_in(seen, sets's set_of(list of 1))     # {2, 3, 4}: in the first, not the second
for each x in sets's items_of(seen)        # its things, as a list
    say x
end

take_out(s, x) takes x out if it's there, in_one(a, b) is what's in one but not both, size(s) how many, is_within(a, b) whether everything in a is in b, same(a, b) whether they hold the same things, and copy_of(s) a set of its own with the same things.
