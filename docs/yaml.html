What it's for

YAML, the settings files of CI, Kubernetes, Docker Compose and many more: read into dictionaries, lists and values, and written back, as Python's yaml.safe_load and yaml.safe_dump do. In Moth alone, so it works everywhere.

use "yaml.moth" as yaml
set settings to yaml's read_yaml(read "settings.yaml")
say item "port" of item "server" of settings
for each step in item "steps" of settings
    say step
end
set documents to yaml's read_yaml_all(read "all.yaml")   # each document, after its ---, in a list
write yaml's yaml_of(settings) to "settings.yaml"

Mappings become dictionaries, their keys text as written; sequences become lists; and scalars are read as YAML 1.2 has them: true and false are yes and no; null, ~ and nothing at all are nothing; 12, -3, 0x1F, 0o17, 1.5, 6.02e23 and .inf are numbers; everything else is text, quoted or not, so on, no, 1.2.3 and 2026-11-04 stay text. Both styles: block (indented, a - before each item) and flow ([a, b] and {a: 1}); 'single' and "double" quotes, with \n, \t, é and YAML's other escapes; | and > for text of many lines, with - and + for its last line ends; # comments; documents split by --- and ended by ...; anchors (&base), aliases (*base) and merges (<<: *base); and the tags !!str, !!int, !!float, !!bool, !!null and !!binary (bytes), while others, as !Ref, are passed over. A file that isn't YAML is a fail with that says which line and why: catch it with try.

yaml_of writes a dictionary, list or value as block YAML that reads back as it was: text quoted where it would read as something else, text of many lines after a |, bytes as !!binary, records as mappings.

yaml's read_yaml(words)

the first document's value, or nothing for a file with none

Inputs

  • words

Written to read_yaml with words, at yaml.moth line 42

Example

use "yaml.moth" as yaml
to doc with parts
    return (join parts with "\n") + "\n"
end
say yaml's read_yaml(doc(list of "- Mark McGwire", "- Sammy Sosa", "- Ken Griffey"))
["Mark McGwire", "Sammy Sosa", "Ken Griffey"]

yaml's read_yaml_all(words)

every document's value, in order

Inputs

  • words

Written to read_yaml_all with words, at yaml.moth line 51

Example

use "yaml.moth" as yaml
to doc with parts
    return (join parts with "\n") + "\n"
end
set two to yaml's read_yaml_all(doc(list of "# Ranking of 1998 home runs", "---", "- Mark McGwire", "- Sammy Sosa", "", "# Team ranking", "---", "- Chicago Cubs"))
say two
[["Mark McGwire", "Sammy Sosa"], ["Chicago Cubs"]]

yaml's yaml_of(value)

a value as block YAML, ending with a line end

Inputs

  • value

Written to yaml_of with value, at yaml.moth line 1293

Example

use "yaml.moth" as yaml
set items_list to list of (dictionary where "name" is "x", "tags" is (list of "a", "b")), (list of 1, 2), empty list, empty dictionary
say yaml's yaml_of(items_list)
- name: x
  tags:
    - a
    - b
- - 1
  - 2
- []
- {}
