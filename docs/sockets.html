What it's for

Talking to other programs over a network, as Python's socket and ssl modules do, on Windows and Linux: connections out and in (TCP), secure ones (TLS), and messages (UDP), with IPv4 or IPv6 addresses or names. A program folio build makes can use it, built with --allow-libraries.

use "sockets.folio" as net
set c to net's connect("example.com", 80)
set line_end to (list of 13, 10) as bytes as text
net's send(c, "GET / HTTP/1.0" + line_end + "Host: example.com" + line_end + line_end)
say net's receive_all(c) as text
net's close(c)

set c to net's connect_secure("example.com", 443)   # TLS, its certificate checked for that name
net's secure(c, "mail.example.com")       # or a connection made secure after it began, as STARTTLS does
net's trust("my-ca.pem")                  # certificates trusted besides the system's own
net's secure_as_server(c, "cert.pem", "key.pem")  # a connection accept() took, as its server

set listener to net's listen(9000)        # this computer alone; listen_everywhere(9000) for every network
set listener to net's listen_on("::", 9000)  # an address of its own: "::1", "::" for IPv6 and IPv4 both
set c to net's accept(listener)           # waits for one; peer of c says who: (record with host ..., port ...)
say net's receive(c, 1024) as text        # up to 1024 bytes, as soon as some come; none once it's closed
net's wait_at_most(c, 5000)               # then a receive that waits longer than 5 seconds fails
net's finish_sending(c)                   # no more to send: the other end's receive_all ends
set waiting to net's ready(list of listener, c, d, 1000)  # those with something to take, within a second

set u to net's open_messages(9001)        # UDP, on a port of its own (0 for any); open_messages_on("::", 9001)
net's send_message(u, "127.0.0.1", 9002, "hi")
set m to net's receive_message(u, 1500)   # (record with data ..., host ..., port ...)

Each fails with a fail with that says why when the network does: catch it with try. Secure connections use OpenSSL 3: Linux has it; on Windows its two DLLs go beside the program, libssl-3.dll and libcrypto-3.dll (as Python has them in its DLLs folder) or libssl-3-x64.dll and libcrypto-3-x64.dll (as Git for Windows and the Win64 OpenSSL installer have them). On Windows the certificates it trusts are the system's own.

net's connect(host, port)

A connection to a host, by its name or address. A host with more than one address, as "localhost" has (::1 and 127.0.0.1), is tried as RFC 8305 has it: the first address, then the next every quarter of a second while those before it are still trying, the first to connect kept. So an address that doesn't answer, or an IPv6 one that can't be reached, costs a quarter of a second, not the time it takes to give up.

net's ready(sockets, milliseconds)

Those of these listeners, connections and sockets for messages that have something to take now: a connection waiting to be accepted, bytes or a message to receive, or an end (a receive that gives no bytes, or fails). It waits for one up to this many milliseconds (0 not at all; nothing for as long as it takes), and gives them in the order they were given, none if the time ran out.
