What it's for

A web server, as a program folio build makes can be one, on Windows and Linux: each request a browser (or any other program) makes is given to a function of the program's, which says what to send back.

use "server.folio" as web
to answer with request
    if path of request is "/"
        return "<h1>Hello from Folio</h1>"
    end
    return record with status 404, body "There's nothing at " + path of request
end
web's serve(8080, answer)

A request is a record: its method ("GET", "POST" and the rest), path ("/notes"), query (a dictionary of what came after the ?, decoded), version ("HTTP/1.1"), headers (a dictionary, each name in small letters) and body (text; body_bytes has its bytes). The function gives back text, sent as a page if it starts with "<" and as plain text if not; a list or a dictionary, sent as JSON; or a record with any of status (200 if it has none), body (text or bytes), type (as "text/css"), headers (a dictionary) and file (a file's name, whose bytes are the body, its type from its name). A mistake in it is sent as 500, and said to the error output, and the server goes on.

Many connections at once (DESIGN §123): the server waits for whichever of them has something to say, reads what has come and answers when a whole request is there, so one client that sends a byte at a time, or that stops halfway, holds up nobody. A connection is kept open for the requests after the first (HTTP/1.1 keep-alive), and answers them in the order they came, even when they come together. Each request is given timeout milliseconds to arrive once it has begun, and a kept connection idle_timeout to begin the next; one that goes over is answered 408 and closed. An answer the other end takes none of for timeout is cut off. A request bigger than most_bytes is answered 413, headers over 64 KB 431, and one that can't be read 400. Only most_connections are held at once, and while they are, the rest wait in the system's own queue.

web's set_timeout(30000)          # how long a request has to arrive, once begun, or an answer can wait
web's set_idle_timeout(5000)      # how long a kept connection may sit with nothing on it
web's set_most_bytes(16777216)    # the biggest request, headers and body together
web's set_most_connections(1024)  # how many are held at once (by each worker)
web's set_most_requests(1000)     # how many a connection answers before it's closed
web's set_keep_alive(no)          # a connection closed after each request, as HTTP/1.0 had it
web's set_workers(4)              # answered on 4 workers; 0 for one a core
web's serve_everywhere(8080, answer)              # from every network the computer is on
web's serve_on_workers(8080, answer, 4)           # on 4 workers at once, each a core of its own
web's serve_secure(8443, answer, "cert.pem", "key.pem")   # HTTPS
web's stop_serving()              # in a handler: serve returns once what's being sent is sent

serve() answers this computer alone (127.0.0.1); serve_everywhere() every network it's on. stop_serving() ends serve() once the requests it's answering are sent. Built with --allow-libraries.

Workers (DESIGN §124): set_workers(4), or serve_on_workers(8080, answer, 4), answers on 4 workers at once, each with a core, its own copy of the program's variables and its own connections, so a handler that does a lot of work holds up only the connections of its own worker. A handler there changes its worker's copy of a variable, which no other worker sees, so what is to be kept and shared goes in a database or a file. stop_serving() ends the worker it's called on, and serve() ends once every worker has.

serve_secure(443, answer, "cert.pem", "key.pem") answers with HTTPS instead, through OpenSSL 3, with a certificate (and the chain after it) and its key, each in a PEM file; serve_secure_everywhere() as well. Linux has OpenSSL; on Windows, OpenSSL's two DLLs go beside the program: libssl-3.dll and libcrypto-3.dll, as Python has them in its DLLs folder, or libssl-3-x64.dll and libcrypto-3-x64.dll, as Git for Windows has them in its mingw64 folder, and the Win64 OpenSSL installer too.
