What it's for

Learning, as PyTorch has it: matrices of numbers, on the graphics card when there is one (gpu.folio) and on the processor when there isn't (arrays.folio), each operation on them remembered, so backward() works out how a loss changes with every number that went into it, and optimizers that move a network's parameters against that.

use "learn.folio" as learn
set net to learn's network(list of 256, 64, 10)       # 256 numbers in, 64 between, 10 out
set opt to learn's adam(learn's parameters_of(net), 0.01)
set x to learn's matrix(pictures)                      # a list of rows, each a list of numbers
for each round from 1 to 20
    set loss to learn's cross_entropy(learn's forward(net, x), labels)   # a place from 0 for each row
    learn's backward(loss)
    say learn's value(loss)                            # the number it is
    learn's step(opt)                                  # the parameters moved; the round's matrices let go
end
say learn's accuracy(learn's forward(net, x), labels)  # how many rows it gets right, from 0 to 1

Matrices: matrix(rows), matrix_of(numbers, rows, columns), zeros(rows, columns), random_normal(rows, columns, spread), and parameter(m), a matrix that learns. On them: matmul(a, b), plus, minus and times (each number with each, or times a number), add_row(m, row), a row added to each row (a layer's bias), relu, sum, mean, cross_entropy(scores, labels) and mean_squared_error(m, target). Then backward(loss), and value(m), numbers_of(m), rows_of(m), shape_of(m), gradient_of(p), softmax_of(m) and accuracy(scores, labels). Layers: layer(inputs, outputs), network(sizes), forward(net, x) and parameters_of(net). Optimizers: sgd(parameters, rate) and adam(parameters, rate), moved on by step(opt). forget() lets go of every matrix worked out since the last step, for a program that only uses a network; free(m) lets go of one.

A program that uses the card is run or built with --allow-libraries; without that, or with no NVIDIA card, it all works on the processor, more slowly, and use_card(no) asks for that. On the card numbers are floats, about 7 digits, as machine learning keeps them. A matrix worked out before a step is let go at the step: its value is a mistake after, so a loss is read with value() first.
