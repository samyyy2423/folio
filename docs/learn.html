What it's for

Learning, as PyTorch has it: matrices of numbers, on the graphics card when there is one (gpu.folio) and on the processor when there isn't (arrays.folio), each operation on them remembered, so backward() works out how a loss changes with every number that went into it, and optimizers that move a network's parameters against that.

use "learn.folio" as learn
set net to learn's network(list of 256, 64, 10)       # 256 numbers in, 64 between, 10 out
set opt to learn's adam(learn's parameters_of(net), 0.01)
set x to learn's matrix(pictures)                      # a list of rows, each a list of numbers
for each round from 1 to 20
    set loss to learn's cross_entropy(learn's forward(net, x), labels)   # a place from 0 for each row
    learn's backward(loss)
    say learn's value(loss)                            # the number it is
    learn's step(opt)                                  # the parameters moved; the round's matrices let go
end
say learn's accuracy(learn's forward(net, x), labels)  # how many rows it gets right, from 0 to 1

Matrices: matrix(rows), matrix_of(numbers, rows, columns), zeros(rows, columns), random_normal(rows, columns, spread), and parameter(m), a matrix that learns. On them: matmul(a, b), plus, minus and times (each number with each, or times a number), add_row(m, row), a row added to each row (a layer's bias), relu, sum, mean, cross_entropy(scores, labels) and mean_squared_error(m, target); and for transformers, embedding(table, ids), gelu(m), layer_norm(m, gamma, beta) and attention(q, k, v, batch, time, heads), with a causal mask. Then backward(loss), and value(m), numbers_of(m), rows_of(m), shape_of(m), gradient_of(p), softmax_of(m) and accuracy(scores, labels). Layers: layer(inputs, outputs), network(sizes), forward(net, x) and parameters_of(net). dropout(m, chance) while training(yes), as at first; training(no) to use what it learned. Optimizers: sgd(parameters, rate), adam(parameters, rate) and adamw(parameters, rate, decay), moved on by step(opt); clip_gradients(opt, most) and gradient_norm(opt), and cosine_rate(s, steps, warmup, top, bottom) for opt's rate at each step, set as set opt's rate to .... forget() lets go of every matrix worked out since the last step, for a program that only uses a network; free(m) lets go of one. save(named, file), load(file) and load_into(named, file) keep matrices in a safetensors file, as Hugging Face does, and named_parameters(net) names a network's; save(named, file, "F16") or "BF16" keeps 16-bit floats, in half the room. custom(inputs, forward, backward) is an operation of your own, which trains as these do: forward makes the result from the inputs, and backward each input's gradient from the result's, with learn's operations or kernels of your own on the card.

A program that uses the card is run or built with --allow-libraries; without that, or with no NVIDIA card, it all works on the processor, more slowly, and use_card(no) asks for that. On the card numbers are floats, about 7 digits, as machine learning keeps them. A matrix worked out before a step is let go at the step: its value is a mistake after, so a loss is read with value() first.

use "learn.folio" as learn
to check_gradients with make_loss, names, starts
    set params to empty list
    for each s in starts
        add learn's parameter(learn's matrix(s)) to params
    end
    learn's backward(make_loss(params))
    set worked to empty list
    for each p in params
        add learn's numbers_of(learn's gradient_of(p)) to worked
    end
    learn's forget()
    set h to 0.00001
    for each k from 1 to length of starts
        set numbers to learn's numbers_of(learn's matrix(item k of starts))
        for each j from 1 to length of numbers
            set up to learn_value_with(make_loss, starts, k, j, h)
            set down to learn_value_with(make_loss, starts, k, j, -h)
            set slope to (up - down) / (2 * h)
            set got to item j of item k of worked
            set off to got - slope
            if off is less than 0
                set off to -off
            end
            expect off is less than 0.0001 + 0.0001 * (slope * slope)
            if off is at least 0.0001 + 0.0001 * (slope * slope)
                say item k of names + " " + j + ": backward " + got + ", the slope " + slope
            end
        end
    end
end
to learn_value_with with make_loss, starts, k, j, h
    set params to empty list
    set i to 0
    for each s in starts
        add 1 to i
        set m to learn's matrix(s)
        if i is k
            set numbers to learn's numbers_of(m)
            set item j of numbers to item j of numbers + h
            set m to learn's matrix_of(numbers, length of s, length of item 1 of s)
        end
        add learn's parameter(m) to params
    end
    set got to learn's value(make_loss(params))
    learn's forget()
    return got
end
to loss_embedding with ps
    set target to learn's matrix(list of (list of 1, 0, 2), (list of 0.5, 1, -1), (list of 2, 2, 0), (list of 1, 0, 2))
    return learn's mean_squared_error(learn's embedding(item 1 of ps, list of 2, 0, 2, 1), target)
end
to loss_gelu with ps
    set w to learn's matrix(list of (list of 1, -2, 0.5), (list of 3, 1, -1))
    return learn's sum(learn's times(learn's gelu(item 1 of ps), w))
end
to loss_attention with ps
    set w to learn's matrix(list of (list of 1, -2, 0.5, 2), (list of 3, 1, -1, 0.25), (list of -1, 1, 2, 1),
        (list of 0.5, 0.5, -2, 1), (list of 2, -1, 1, 1), (list of -0.5, 1.5, 1, -1))
    return learn's sum(learn's times(learn's attention(item 1 of ps, item 2 of ps, item 3 of ps, 2, 3, 2), w))
end

learn's custom(inputs, forward, backward)

An operation learn hasn't got, which trains as learn's own do. forward is given the inputs, a list of matrices, and gives the result, a matrix. backward is given the result's gradient, a matrix of the result's shape, then the inputs and the result, and gives a list with each input's gradient, a matrix of that input's shape, or nothing for one it doesn't change. Neither is remembered for backward, so either can work with learn's operations, or with kernels of your own on the card, launched with gpu.folio on each matrix's data.

Inputs

  • inputs
  • forward
  • backward
