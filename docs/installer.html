What it's for

A program's installer, as moth build app.moth --installer makes one, on Windows and Linux. Run, it asks, then puts the program where a person's own programs go, with no administrator needed: on Windows in AppData\Local\Programs, in the Start menu, and in Settings' list of installed apps, which can remove it; on Linux in ~/.local/opt, in the applications menu, and with an uninstall.sh beside it. Run with --uninstall, it takes the program away again; --quiet asks nothing and says only what went wrong; --into <folder> puts it there and makes no menu entry, for a program carried around in a folder.

use "installer.moth" as installer
installer's setup("Notes", "1.2.0", "notes.exe", nothing)    # the program built in: --include notes.exe

The fourth input is the name of a PNG icon built in too, for Linux's menu, or nothing. Built with --allow-all, as moth build --installer builds it.
