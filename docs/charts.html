What it's for

Charts written to files, as matplotlib's savefig makes them: bars, lines, and one bar split into its parts, as SVG (sharp at any size, for pages and documents; each mark says its value when the mouse is on it) or as PNG, from labels and numbers. In Moth alone, so it works everywhere.

use "charts.moth" as charts
set months to list of "Jan", "Feb", "Mar", "Apr"
set sales to charts's bar_chart("Sales by month", months, list of 120, 95, 140, 160)
charts's save(sales, "sales.svg")                     # or "sales.png", by the name's end
set both to dictionary where "2025" is (list of 120, 95, 140, 160), "2026" is (list of 130, 120, 150, 180)
charts's save(charts's line_chart("Sales", months, both), "sales-lines.png")   # a line for each
charts's save(charts's parts_chart("Where it went", (list of "Rent", "Food", "Fun"), list of 50, 30, 20), "budget.png")

A dictionary of lists is a series for each key, up to 8, each its own colour in a fixed order, with a legend; a line chart names its lines at their ends too, up to 4. sized(chart, width, height) is the same chart another size (720 by 440 to begin with); svg_of and png_of give the file's text and bytes.
