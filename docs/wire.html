What it's for

Bytes to and from a connection a message at a time, as the protocols of databases have them: a reader that keeps what came and isn't used yet, so lines, exact counts of bytes and the numbers in them come off it as they're wanted; and a writer that puts bytes, text and numbers together, to send at once. redis.moth, postgres.moth and mysql.moth speak through it, on sockets.moth.

use "wire.moth" as wire
set reader to wire's reader(connection)           # a connection of sockets.moth's
set line to wire's line(reader)                   # the bytes up to the next \r\n, as text, without it
set block to wire's take(reader, 16)              # exactly 16 bytes, waiting for them to come
set n to wire's number_of(block, 1, 4, "big")     # 4 bytes from byte 1, the highest first; or "little"
set out to wire's writer()
wire's add_text(out, "SELECT 1")                  # its UTF-8; add_bytes, add_byte, add_number(out, n, 4, "big")
net's send(connection, wire's bytes_of(out))

number_of and signed_of read whole numbers of 1 to 8 bytes (signed ones as two's complement), double_of a float of 8 (IEEE 754), and add_number, add_double write them. A connection that closes in the middle of a message is a fail with.
