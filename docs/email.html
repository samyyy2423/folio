What it's for

Email, as Python's smtplib, email, poplib and imaplib have it: a message with text, a page of HTML and files, sent through a mail server over SMTP, secure from the start (port 465) or after STARTTLS (587), logged in; and messages read: from MIME, and from a mailbox over POP3 or IMAP. A program moth build makes can use it, built with --allow-libraries (and --allow-read, to attach files).

use "email.moth" as mail
set server to mail's server("smtp.example.com", 587)
mail's log_in(server, "me@example.com", "an app password")
set m to mail's message("Sam <me@example.com>", "you@example.com", "Hello", "Hi there,\nall well?")
set cc of m to list of "them@example.com"           # and bcc, reply_to
set html of m to "<p>Hi there, <b>all well?</b></p>"  # shown instead of the text where it can be
mail's attach(m, "report.pdf")                       # or attach_bytes(m, "notes.txt", data, "text/plain")
mail's send(server, m)

set inbox to mail's server("imap.example.com", 993)
mail's log_in(inbox, "me@example.com", "an app password")
set box to mail's imap_open(inbox)
mail's imap_select(box, "INBOX")                     # how many messages it has
for each uid in mail's imap_search(box, "UNSEEN")
    set got to mail's imap_get(box, uid)            # a message, as read_message reads one
    say sender of got + ": " + subject of got
end
mail's imap_close(box)                               # pop_open, pop_count, pop_get, pop_delete, pop_close
say mail's imap_folders(box)                         # each folder's name
mail's imap_mark(box, uid, "\\Seen")                 # a flag on a message

set pop_server to mail's server("pop.example.com", 995)
mail's log_in(pop_server, "me@example.com", "an app password")
set pop_box to mail's pop_open(pop_server)
for each n from 1 to mail's pop_count(pop_box)       # how many messages there are
    say subject of mail's pop_get(pop_box, n)       # each read as read_message reads one
    mail's pop_delete(pop_box, n)                   # deleted when the box is closed
end
mail's pop_close(pop_box)

set text to mail's message_text(m)                   # the message as it's sent, in MIME
say subject of mail's read_message(text)             # Hello
mail's attach_bytes(m, "notes.txt", "milk, eggs" as bytes, "text/plain")
say mail's base64_of("hi") " " mail's bytes_of_base64("aGk=") as text   # aGk= hi

A server is a record: host, port, security ("tls" for 465, 993 and 995, else "starttls"; "none" in the clear, for a server of one's own), user and password (nothing until log_in), name (what it says it is, "localhost"), trust (a PEM file of certificates to trust besides the system's, or nothing) and time_limit (the milliseconds an answer may take, 30000). A message is a record: sender, recipients, cc and bcc (lists of addresses, as "you@example.com" or "You <you@example.com>"), reply_to, subject, text, html, attachments and headers (a dictionary of others). message_text(m) is the message as it's sent, in MIME; read_message(raw) reads one back, with its date and message_id too. send() fails with what the server said when it says no. base64_of and bytes_of_base64 are base64's two ways.
