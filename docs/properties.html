What it's for

Property-based testing, as Python's Hypothesis and Haskell's QuickCheck do it: say what should be so for every value of a sort, and for_all tries it on a hundred values made at random, small ones first. When one shows it isn't so, that value is made as small as it can be while it still shows it, and the mistake says the simplest one, with the seed that makes the same values again. In Folio alone, so it works everywhere.

use "properties.folio" as p

to test_sorting_twice_is_sorting_once
    set numbers to p's list_of(p's whole_number(-1000, 1000))
    p's for_all(numbers, (function with xs gives ((xs in order) in order) is (xs in order)))
end

A property gives yes when it holds and no when it doesn't, or uses expect as a test does: a mistake inside it counts as its not holding. What makes the values, a generator, is one of these, or made from them:

whole_number(low, high)       whole numbers from low to high: near 0 first, and the two ends now and then
decimal(low, high)            numbers with up to 3 decimals, from low to high
yes_or_no()                   yes or no
any_text()                    text of letters, digits, spaces, punctuation, tabs and new lines, and some
                              letters beyond ASCII (é, ß, λ, 中)
text_of(letters)              text of only those letters: text_of("ab") makes "", "b", "ab", "abba", ...
one_of(values)                one of the list's values; the first is the simplest
either_of(generators)         a value one of the generators makes
list_of(generator)            lists of up to 20 of what the generator makes
dictionary_of(keys, values)   dictionaries of up to 10 keys, each made by the first generator, and values
                              by the second
mapped(generator, change)     what change makes of each value: mapped(whole_number(1, 9), double)
kept(generator, test)         only the values test says yes to

for_all_with(settings, generator, property) takes a dictionary of "tries" (100 if it isn't given) and "seed" (one at random if it isn't): the seed a mistake says makes the same values again, so the same mistake. sample(generator, seed, count) gives count values, to see what a generator makes.
