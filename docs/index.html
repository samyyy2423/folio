The standard library

Everything Moth carries.

49 libraries and 807 functions, from JSON and web servers to databases, charts and encryption, each built into moth, so use "json.moth" as json works in any folder. Each function, what it takes, what it gives, and an example, made from the libraries' own comments.

Text and data

Reading and writing the formats data comes in, and working with text, dates and numbers.

json.mothReads JSON, the format most of the web speaks, into Moth's own values: an object becomes a dictionary, an array a list, true and false yes and no, and null nothing.1 function yaml.mothYAML, the settings files of CI, Kubernetes, Docker Compose and many more.3 functions toml.mothTOML (v1.0), the settings files Python's tomllib reads (pyproject.toml, Cargo.toml and many more): read into dictionaries and lists, and written back.2 functions xml.mothReads XML into records, and writes them back.8 functions text.mothText: patterns to find, check and replace (regular expressions), numbers written with so many decimals or with commas, text padded to a width, and CSV, read and written.13 functions dates.mothDates on the calendar: today's, one read from "2026-11-03", days added and counted between, weekdays, and a date written as a person wants it.16 functions zones.mothTime zones, as Python's zoneinfo has them.7 functions base64.mothBytes as text and back, as Python's base64 module has them.6 functions zip.mothSqueezes bytes smaller and back, as gzip and .zip files do, in Moth alone: DEFLATE (RFC 1951), gzip (RFC 1952) and zip archives.7 functions images.mothPictures from PNG and JPEG files, and back, as Pillow's Image has them, in Moth alone.11 functions charts.mothCharts written to files, as matplotlib's savefig makes them.7 functions
