What it's for

Excel workbooks (.xlsx), read and written in Folio alone: each sheet a list of rows, each row a list of its cells, a cell a number, text, yes or no, or nothing for an empty one. Excel, LibreOffice and Google Sheets open what it writes; it reads what they write.

use "xlsx.folio" as xlsx
set book to xlsx's workbook()
set rows to list of (list of "Month", "Sales"), (list of "January", 120), (list of "February", 95.5)
xlsx's sheet(book, "Sales", rows)
xlsx's save(book, "sales.xlsx")

set sheets to xlsx's read_book(read bytes "sales.xlsx")   # a dictionary: each sheet's name, its rows
say item 2 of item 1 of xlsx's rows_of(read bytes "sales.xlsx")

A date in a cell is the number Excel keeps it as, days since 30 December 1899. A file that isn't a workbook is a fail with that says why. save() is built with --allow-write.

xlsx's sheet(book, name, rows)

a sheet at the end of the workbook: its name (at most 31 characters, none of : \ / ? * [ ]) and its rows

Inputs

  • book
  • name
  • rows

Written to sheet with book, name, rows, at xlsx.folio line 28

Example

use "xlsx.folio" as xlsx
set book to xlsx's workbook()
set sales to list of (list of "Month", "Sales", "Done"), (list of "January", 120, yes), (list of "Fe<b> & \"co\"", 95.5, no), (list of " spaced ", nothing, 0.1 + 0.2)
xlsx's sheet(book, "Sales", sales)
say xlsx's rows_of(xlsx's bytes_of(book))
[["Month", "Sales", "Done"], ["January", 120, yes], ["Fe<b> & \"co\"", 95.5, no], [" spaced ", nothing, 0.3]]
