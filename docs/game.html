What it's for

Games, on Windows and Linux: a window drawn again about 60 times a second, what's held on the keyboard, where the mouse is, pictures and sounds. On ui.moth, so it needs windows.moth, linux.moth and ui.moth beside it, and is built with --allow-libraries (and --allow-read for pictures and sounds that aren't built in).

use "game.moth" as game
set x to 100
to update with seconds                  # how long since the last frame, about a 60th of a second
    if game's key_down("Right")
        set x to x + 200 * seconds
    end
end
to show with canvas
    game's colour(canvas, 20, 20, 40)
    game's rectangle(canvas, 0, 0, 640, 480)
    game's draw_image(canvas, ship, x, 200)
end
game's window("Space", 640, 480)
set ship to game's image("ship.png")
game's run_game(update, show)

And in update, or show:

if game's mouse_down()                  # where it is: mouse_x() and mouse_y()
    game's circle(canvas, game's mouse_x(), game's mouse_y(), 10)
end
game's line(canvas, 0, 400, 640, 400)
game's draw_image_sized(canvas, ship, 300, 200, 64, 48)
game's sound("boom.wav")
say game's frames()                     # so far
game's stop_game()                      # the window closed, which ends run_game

update is called first, then show, each frame. on_key's handler is given each key as it's pressed, and on_click's where the mouse was clicked; stop_game closes the window, which ends run_game.
