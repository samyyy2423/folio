Every library · The source

What it's for

Arrays of numbers, as NumPy has them: a shape, and the numbers row after row, with maths on all of them at once, matrix multiplication, sums, means and the largest along an axis, reshaping, slicing and broadcasting. A program folio build makes does the work in machine code, loops of Folio's own (DESIGN §118) over the numbers where they are, one after another in memory; anywhere else, the same in Folio, with the same answers.

use "arrays.folio" as arrays
set a to arrays's array(list of (list of 1, 2, 3), (list of 4, 5, 6))
say a's shape                               # [2, 3]
say arrays's plus(a, 10)                    # [[11, 12, 13], [14, 15, 16]]: a number goes with every one
say arrays's times(a, arrays's array(list of 1, 0, -1))   # each row times [1, 0, -1] (broadcasting)
set b to arrays's transpose(a)              # 3 by 2
say arrays's matmul(a, b)                   # [[14, 32], [32, 77]]
say arrays's sum(a)                         # 21; sum(a, 1) adds down axis 1: [5, 7, 9]
say arrays's mean(a, 2)                     # [2, 5]; also max, min, argmax
say arrays's reshape(a, list of 3, 2)       # the same numbers, 3 by 2; -1 for one axis works it out
say arrays's slice(a, 2, 2, 3)              # axis 2, from its 2nd to its 3rd: [[2, 3], [5, 6]]
say arrays's value_at(a, list of 2, 3)      # 6: places count from 1, as items do

Made with array(nested lists), shaped(numbers, shape), zeros(shape), ones(shape), filled(shape, x), random(shape) (from 0 up to 1), random_normal(shape), counting(first, last, step), evenly(first, last, n) and identity(n). Element by element: plus, minus, times, divided_by, maximum, minimum (each of two arrays, or an array and a number), negate, absolute, square, relu, above_zero (relu's slope), sqrt, exp, ln, tanh, sigmoid, power(t, p) and apply(t, f). Then matmul, dot, transpose, flatten, row, stack, join_along, softmax, to_list, numbers_of, copy_of, size, rank, close(a, b) and same(a, b). Axes and places count from 1. A shape that can't be, shapes that don't go together, or a place outside an array is a fail with that says so.

arrays's use_blas()

Has matmul use BLAS from now on, for all but the smallest: OpenBLAS (libopenblas.dll on Windows, from github.com/OpenMathLib/OpenBLAS/releases, beside the program; libopenblas.so.0 on Linux, from its packages), or NumPy's own (numpy.libs/libscipy_openblas64_-*.dll, copied beside the program as libscipy_openblas64_.dll). Gives which it found, "openblas" or "openblas64", or nothing, when matmul stays as it was. A program that uses it is built with --allow-libraries. BLAS adds in its own order, so its answers can differ from Folio's in the last digits, as NumPy's do.

Inputs

Takes nothing.
