What it's for

Work in the background, on Windows and Linux: another program, started and left to run while this one goes on, whose output and the number it ends with are there when it's done. A slow job of this program's own can be one too: start_self starts this same program with other arguments, which it can look at to do the job.

use "tasks.folio" as tasks
if length of arguments is at least 1 and item 1 of arguments is "count"
    set total to 0                        # the job, in the program started in the background
    for each i from 1 to 100000000
        add i to total
    end
    say total
    stop the program with 0
end
set job to tasks's start_self(list of "count")
repeat while not tasks's done(job)          # or ask in a window's timer, so the window goes on
    say "working..."
    tasks's pause(200)
end
say "the total is " + tasks's output_of(job)
set zipping to tasks's start("zip", list of "-r", "backup.zip", "notes")   # another program
tasks's wait_for(zipping)
say tasks's code_of(zipping)                # 0 when it went well
tasks's stop_task(job)                      # ended now, if it hasn't ended yet
say tasks's own_program()                   # where this program is

done() doesn't wait: it takes what the task has said so far, and says whether it has ended. wait_for() waits. output_of() is all it said, to its output and its error output, as text; code_of() the number it ended with. Built with --allow-libraries.
