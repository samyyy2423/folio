What it's for

Numbers on the graphics card, worked on there: NVIDIA's, through CUDA's driver (DESIGN §158). Lists of numbers go up to the card, as 32-bit floats, as graphics cards keep them, are added, multiplied, matrix-multiplied and summed there, thousands at a time, and come back as lists. The card's code is written here in PTX, which the driver makes the card's own as it loads, so nothing but the driver is needed: no CUDA toolkit.

use "gpu.folio" as gpu
if gpu's available()
    say gpu's device()                          # its name, memory, capability and processors
    set a to gpu's upload(list of 1, 2, 3)      # on the card
    set b to gpu's upload(list of 10, 20, 30)
    say gpu's download(gpu's plus(a, b))        # [11, 22, 33]
    say gpu's sum(a)                            # 6
end

A program that uses it is run or built with --allow-libraries. On a computer with no NVIDIA card, or no driver, available() is no and the rest is a fail with that says so. Numbers on the card are floats: about 7 digits, not Folio's 15, as machine learning wants them.
