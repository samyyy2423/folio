What it's for

Pictures from PNG and JPEG files, and back, as Pillow's Image has them, in Folio alone. An image is a record with its width, its height, and its pixels: bytes, 4 for each pixel (red, green, blue, and how opaque, each 0 to 255), row by row from the top left.

use "images.folio" as images
set photo to images's read_image("cat.jpg")            # a PNG or a JPEG, by what the file holds
say width of photo " by " height of photo
say images's pixel(photo, 0, 0)                         # [255, 128, 0, 255]: red, green, blue, opacity
images's set_pixel(photo, 0, 0, list of 0, 0, 0, 255)
write images's png_of(photo) to "cat.png"
write images's jpeg_of(images's resized(photo, 100, 75), 85) to "small.jpg"   # quality from 1 to 100
set blank to images's new_image(64, 64, list of 255, 255, 255, 255)

It reads PNG of every kind (grey, colour, a palette, with or without opacity, 1 to 16 bits, interlaced) and JPEG as cameras and most programs write it (baseline, grey or colour, any sampling); a progressive JPEG, as some web pages hold, is a mistake that says so. image_from(bytes) reads what a file held; cropped, resized (each pixel the nearest one's), flipped (left to right) and grey make new images. Pixels count from 0, as Pillow's do.
