What it's for

MCP servers: tools, resources and prompts that Claude and other AI apps can use, served over the Model Context Protocol on a program's input and output, a JSON-RPC message a line, as such an app starts the program. A tool is a function the app can call with what it needs as a dictionary; a resource, text it can read by its address; a prompt, a message it can be given, made from what it's told.

use "mcp.folio" as mcp
to add_up with given
    return item "a" of given + item "b" of given
end
set calc to mcp's server("calculator", "1.0.0")
set needs to dictionary where "a" is "number", "b" is "number"
mcp's tool(calc, "add", "Adds two numbers", needs, add_up)
mcp's serve(calc)

Built with folio build calc.folio, the app runs calc.exe (or calc on Linux) as its own program: in Claude Desktop's claude_desktop_config.json, "mcpServers": {"calculator": {"command": "C:\\tools\\calc.exe"}}. What a tool needs is a dictionary of each input's name and what it is: "number", "whole number", "text", "yes or no", "list" or "dictionary", with "or nothing" after it for one the call may leave out and ": what it's for" after that, as "text or nothing: a city's name"; or a JSON Schema of its own. A tool's function gives back text, or anything else, sent as JSON; a mistake in it is sent as the tool's error, and the server goes on. Only a program folio builds can serve, as it reads its input as it comes; answer() answers one message anywhere.

  • on
  • address
  • name
  • description
  • type
  • reads

Written to resource with on, address, name, description, type, reads, at mcp.folio line 39

Example

use "mcp.folio" as mcp
to add_up with given
    return item "a" of given + item "b" of given
end
to fails_always with given
    fail with "the sky fell"
end
to listing with given
    return list of 1, "two"
end
to notes_today with address
    return "buy milk"
end
set s to mcp's server("calculator", "1.0.0")
set two to dictionary where "a" is "number: the first", "b" is "number"
mcp's tool(s, "add", "Adds two numbers", two, add_up)
mcp's tool(s, "fail", "Always fails", nothing, fails_always)
set how to dictionary where "how" is "text or nothing"
mcp's tool(s, "list", "Gives a list", how, listing)
mcp's resource(s, "notes://today", "Today", "Today's notes", "text/plain", notes_today)

mcp's answer(on, line)

A message from the app, as the line of JSON it sent, answered: the reply's line of JSON, or nothing for a notification, which has no reply.

Inputs

  • on
  • line

Written to answer with on, line, at mcp.folio line 265

Example

use "mcp.folio" as mcp
to made
    set s to mcp's server("calculator", "1.0.0")
    set two to dictionary where "a" is "number: the first", "b" is "number"
    mcp's tool(s, "add", "Adds two numbers", two, add_up)
    mcp's tool(s, "fail", "Always fails", nothing, fails_always)
    set how to dictionary where "how" is "text or nothing"
    mcp's tool(s, "list", "Gives a list", how, listing)
    mcp's resource(s, "notes://today", "Today", "Today's notes", "text/plain", notes_today)
    set who to dictionary where "name" is "text: who"
    mcp's prompt(s, "greet", "Greets someone", who, greeting_prompt)
    return s
end
to add_up with given
    return item "a" of given + item "b" of given
end
to fails_always with given
    fail with "the sky fell"
end
to listing with given
    return list of 1, "two"
end
to notes_today with address
    return "buy milk"
end
to greeting_prompt with given
    return "Say hello to " + item "name" of given
end
say mcp's answer(made(), "\{\"jsonrpc\": \"2.0\", \"method\": \"notifications/initialized\"}")
nothing
