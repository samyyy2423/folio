What it's for

Random numbers for secrets, as Python's secrets module has them: bytes no one can guess, from the system (BCryptGenRandom on Windows, getrandom on Linux), for passwords, keys and tokens, where random number (which a program can make repeat) won't do. A program moth build makes can use it, built with --allow-libraries.

use "secrets.moth" as secrets
say secrets's random_bytes(16)       # (16 bytes: ...)
say secrets's token_hex(16)          # 32 hex digits
say secrets's token_url(16)          # about 22 letters that can go in an address
say secrets's below(6) + 1           # 1 to 6, each as likely
say secrets's choice(list of "red", "green", "blue")
say secrets's shuffled(list of 1, 2, 3, 4)
say secrets's same_secret(given, kept)   # compares without taking longer where they first differ
