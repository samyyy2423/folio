What it's for

Time zones, as Python's zoneinfo has them: what time it is in any of the world's zones, by its name ("Asia/Kolkata", "America/New_York", "UTC"), with its summer time, and the moment a time in one is. A moment is seconds since 1970 began in UTC, as the system's clock counts them. On Windows the zones are the system's own (ICU, in icu.dll, from Windows 10 1903); on Linux, the zoneinfo files. A program moth build makes can use it, built with --allow-libraries (and on Linux --allow-read, to read the zone's file).

use "zones.moth" as zones
set now to zones's now()                         # seconds since 1970, UTC
set t to zones's in_zone(now, "Asia/Kolkata")    # (record with year, month, day, hour, minute, second,
say t                                            #   offset (seconds east of UTC), zone)
say zones's zone_text(t)                         # 2026-11-04T11:55:38+05:30
say zones's offset_at("America/New_York", now)   # -18000 in winter, -14400 in summer
say zones's moment_of(2026, 7, 4, 9, 0, 0, "America/New_York")   # that time there, as a moment
say zones's local_zone()                         # this computer's own zone's name
say zones's utc_text(now)                        # 2026-11-04T06:25:38Z

A zone that isn't there is a fail with that says so: catch it with try.

zones's moment_of(year, month, day, hour, minute, second, zone)
